We are a growing technology company dedicated to creating accessible and inclusive online learning tools for schools and universities.

1. Accessible E-Learning UI Developer

Job Reference Number: EDT01

Short Description: We are seeking a passionate front-end developer to build WCAG 2.1 compliant interface components for our digital learning platform.

Salary Range: $85,000 – $98,000 AUD per annum

Reporting Line: Reports to the Lead Web Architect.

Key Responsibilities:

  • Develop semantic, high-contrast HTML5 and CSS3 templates for learning modules.
  • Audit existing web components for screen reader compatibility and keyboard navigation.
  • Collaborate with educational designers to optimize online course layouts.

Requirements:

Essential:

  • Proficiency in semantic HTML5, CSS Flexbox/Grid, and web accessibility standards (WCAG 2.1).
  • Experience with Git version control and collaborative workflows.

Preferable:

  • Degree in Information Technology, Computer Science, or related discipline.
  • Prior experience designing for educational or learning management systems (LMS).

2. Interactive Learning Tool Specialist

Job Reference Number: EDT02

Short Description: Seeking a creative interface designer and front-end builder to develop interactive web applications and student engagement widgets.

Salary Range: $90,000 – $105,000 AUD per annum

Reporting Line: Reports to the Product Manager.

Key Responsibilities:

  • Design responsive user interfaces for online quiz engines and virtual classrooms.
  • Conduct cross-browser visual testing and ensure responsive breakpoints work seamlessly on mobile devices.
  • Maintain consistent brand styling across all client-facing digital assets.

Requirements:

Essential:

  • Strong command of responsive CSS layout design and mobile-first principles.
  • Portfolio demonstrating clean visual design and intuitive user experience layouts.

Preferable:

  • Knowledge of SVG graphics and CSS animations.
  • Understanding of user privacy and data security principles in web applications.
